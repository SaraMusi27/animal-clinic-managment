#  Animal Clinic Management System

A full-stack web application designed to simplify daily operations at an animal clinic — including appointment scheduling, pet registration, and client management.

##  Features
- Register, update, and delete animal records  
- Manage client information  
- Schedule, view, and cancel appointments  
- Search and filter pets or clients  
- Secure database integration with SQL  

##  Built With
- **C#** – Backend logic and data handling  
- **HTML** – Page structure and layout  
- **JavaScript** – Dynamic user interactions and validations  
- **SQL** – Database for storing clinic, pet, and client information  

##  Project Purpose
This project was created to demonstrate practical skills in full-stack development using C# and SQL, while building a realistic application that improves clinic efficiency.
